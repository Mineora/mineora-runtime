# Security

This repository documents the Java runtime inside the Mineora Android app. It is not a general
Java distribution.

Server JARs, plugins and mods are executable code. Inside Mineora they run with the app's file and
network permissions, with no sandbox between servers. Only run server software you trust.

## Reporting a problem

Open a GitHub issue for runtime and build-script problems. Include the Mineora version, the server
software and version, and what happened. Do not include credentials, signing keys, server backups,
personal addresses or player worlds.

For a vulnerability, contact the maintainer privately through the support address on the app's
Google Play page before publishing details.
